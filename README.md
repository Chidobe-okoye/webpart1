**## Project Overview**
This is Part 1 of the website project for **Maddison Bakery**, a family-run artisanal bakery in Cape Town.  
The website consists of 5 HTML pages with proper navigation, semantic HTML structure, and relevant content.

## Website Goals and Objectives
- Increase the bakery’s online presence  
- Allow customers to easily browse the current menu and view product images  
- Enable customers to submit enquiries for custom orders (cakes, catering)  
- Provide clear contact information and location details  
- Showcase the bakery’s story, values, and commitment to fresh homemade products  

## Pages Included (5 Pages)
1. `index.html`   - Home Page  
2. `about.html`   - About Us Page  
3. `menu.html`    - Menu Page (with cake images)  
4. `contact.html` - Contact Us Page  
5. `order.html`   - Custom Order Form Page  

## Technologies Used
- HTML5 with semantic elements (`<nav>`, `<main>`, `<section>`, `<header>`, `<footer>`)  
- Basic inline styling for layout and images
